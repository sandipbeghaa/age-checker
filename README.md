# Age Checker

A simple interactive web app built with HTML, CSS, and JavaScript that checks a user's age input and displays instant validation messages.

**Live Site:** https://sandipbeghaa.github.io/age-checker/

## What It Does

- **Age Input & Validation:** Takes a user's age or birth year and checks whether they meet specific age requirements.
- **Instant On-Screen Feedback:** Updates the page immediately with clear, easy-to-read messages without reloading the browser.
- **Clean Responsive Layout:** Styled with custom CSS so it works smoothly on both desktop and mobile screens.

## Built With

- HTML5
- CSS3
- Vanilla JavaScript

## How to Run It Locally

1. Clone or download this repository:
   ```bash
   git clone https://github.com/sandipbeghaa/age-checker
   ```
2. Open the `age-checker` folder.
3. Double-click `index.html` to open it in your browser.
